Cara Menghubungkan HOMEBASE ONLINE dengan GitHub (Hosting & Database)

LANGKAH 1 • HOSTING GRATIS

Upload ke GitHub Pages

  1. Buat repository baru di GitHub.com (misal nama repo: homebase-online, pilih Public).
  2. Upload file HTML aplikasi ini dan ubah namanya menjadi index.html.
  3. Buka menu Settings → Pages pada repository → pada Branch pilih main lalu klik Save.
  4. Aplikasi langsung online 24 jam di alamat https://username.github.io/homebase-online/.
LANGKAH 2 • TOKEN GITHUB (PAT)

Buat Token Akses Database

  1. Di GitHub, klik foto profil kanan atas → Settings → Developer settings.
  2. Pilih Personal access tokens → Fine-grained tokens → Generate new token.
  3. Pilih repository homebase-online, lalu pada Repository permissions ubah Contents menjadi Read and write.
  4. Klik Generate token dan salin kode token (github_pat_...).
LANGKAH 3 • SINKRONISASI DATA

Hubungkan di Dalam Aplikasi

  1. Login ke aplikasi (Akun Master: admin / sandi: @Homebase).
  2. Buka menu Koneksi GitHub & Bagikan Link.
  3. Isi Username GitHub, Nama Repository, dan tempel Token PAT, lalu klik Simpan & Tes Koneksi GitHub.
  4. Setiap absensi, jurnal wali, dan nilai yang disimpan otomatis tersimpan ke file data/homebase_db.json di GitHub!
LANGKAH 4 • MULTI-USER & ORTU

Bagikan Link ke Orang Tua & Guru

  • Orang Tua (Multi-Viewer): Klik tombol Bagikan Link Pantau Orang Tua. Orang tua tidak perlu login maupun token, cukup ketik nama anak.
  • Rekan Guru (Multi-User): Login menggunakan username nama depan guru (misal: aswan / aswan) dan simpan Token PAT satu kali di HP/laptop guru.
  • Tahun Ajaran Baru: Atur kenaikan kelas & kelulusan Kelas 9 di menu Tahun Ajaran, Kelas & Wali.
